# Karina's iPhone 💙⭐️ (Winrina Interactive Phone Experience)

An interactive iOS web application where you explore **Karina (Yu Jimin)**'s iPhone in a cozy Seongsu-dong neighborhood & cafe AU with **Winter (Kim Minjeong)**, **Ningning**, and **Giselle** from **aespa**.

## ✨ Key Features

- **Lock Screen & Passcode (`0101`)**:
  - Features a live clock, flashlight toggle, camera button, multi-language switcher (🌐), and a reminder for **Winter's Birthday (Jan 1 - `0101`)** as the passcode hint.
- **KakaoTalk**:
  - Full chat histories with **Winter ⭐️**, **Ningning 🦋**, **Giselle 🌙**, **aespa Squad (4) 🪐**, **Mom**, **Seongsu Neighbors**, **Ryujin**, and **Yeji**.
  - View selfies, listen to voice messages (Winter's acoustic singing & Karina's whistling), view gifticons, and check shared files.
  - **Real-time Interactive Chat**: At `30s`, Winter texts Karina from *Motungi Cafe*. Tap the message input to auto-type and send replies with realistic iOS keyboard animations.
- **Phone & Live Captions**:
  - Call **Winter**, **Ningning**, **Giselle**, **Mom**, **Ryujin**, or unknown numbers in Recents — each has custom voice call dialogues with **Live Captions**.
  - **Ending Confession Call**: After chatting with Winter, she asks to call you (`180s`) and rings your phone (`260s`) for a full confession scene! Calling her again afterward unlocks a secret **After-Call** dialogue.
- **Instagram (`@imwinter`)**:
  - Browse Winter's profile and watch 3 vertical Reels with swipe-up/down navigation.
- **Music & Dynamic Island**:
  - Listen to 5 tracks/covers by Winter with a Mini Player, full-screen Now Playing sheet, and active **Dynamic Island** equalizer when minimized.
- **Photos, Maps, Notes, Safari, Mail, Calendar, Clock, Weather, Settings & Screen Time**:
  - Explore Karina's pinned notes about Winter's schedule and favorite foods, custom Seongsu-dong interactive map pins, recent Safari searches, and Screen Time stats.

## 🚀 Running Locally

Open `index.html` via any local web server (e.g. VS Code Live Server, `npx serve`, or `python -m http.server`).
